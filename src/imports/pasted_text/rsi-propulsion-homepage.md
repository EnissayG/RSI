You are designing a complete, production-ready website for RSI Propulsion 
(Le Regroupement de Services Intégrés Propulsion), a Montreal-based nonprofit 
organization that provides adapted and affordable housing for adults with 
physical and/or mild cognitive disabilities in the Hochelaga-Maisonneuve 
neighborhood. The site is in French.

This is NOT a generic nonprofit template. Every design decision must feel 
intentional, warm, and specific to this organization's identity.

DESIGN RULES — NON-NEGOTIABLE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
- Border radius: 12px on cards, 8px on buttons, 4px on inputs
- Shadows: soft only — box-shadow: 0 4px 24px rgba(0,0,0,0.07)
- Section padding: 100px top/bottom desktop, 60px mobile
- Orange decorative line (4px tall, 48px wide, #E8621A) above every H2 
  section title — this is the signature visual element throughout the site
- No stock photo clichés (no hands shaking, no generic happy people)
- Image placeholders should be warm-toned, labeled descriptively
- All interactive elements have visible focus ring in #E8621A
- Touch targets minimum 48x48px for accessibility
- WCAG 2.1 AA contrast on every text/background combination
